Sequence · Bridgify v2

Bridge: fingerspell on A, speech on B

Two devices talk through a one-to-one room. Recognition happens on each device; the server sees only small text and landmark packets and passes them straight on.

Server

What the relay does

  • Rooms live in memory: code → {members, createdAt, lastActivity}, max 2 members
  • Codes are 6 characters with no 0/O/1/I/L; a sweeper drops rooms idle for 30 min
  • Each socket: packets ≤ 8 KB, ≤ 40 msgs/s, over the limit it gets {error:'rate'}

Privacy

What stays on the device

  • Fingerspelling: camera → landmarks → letter MLP → committer, all in the browser
  • Speech: Web Speech API, or Whisper in asr.worker if the user opts in
  • Each side renders by its own profile: captions, speech, braille or sign

Measured

Budgets

  • Text packets ≈ 100 B; landmark stream ≤ 15 kbps at 15 Hz
  • Target ≤ 250 ms median relay; RTT from ping acks every 5 s
  • Metrics shown in the Bridge meter and on /about/evidence
