ML pipeline: landmarks to letters

How the fingerspelling letter model is built offline from landmarks only, held to a held-out-signer gate, checked for Python and browser parity, and run on the device.

Steps 3 and 8

Features, identical in Python and TS

  • Wrist to origin, scale by wrist→middle MCP, mirror left hands, z × 0.5
  • Plus 15 joint angles, 10 fingertip distances, palm normal: 63+15+10+3 = 91 per hand
  • ASL F = 91 · ISL F = 91 × 2 + 2 presence mask = 184
  • Parity passes when max abs diff < 1e-5 (features) and < 1e-4 (logits)

Step 6 · focal

The gate

  • Leave-one-signer-out macro-F1 ≥ 0.90 for ASL and ISL static letters
  • The MLP must beat logistic regression by ≥ 3 points, or the simpler model ships
  • Fail: record more signers with the collector, then retrain
  • In the app: commit at p ≥ 0.80 held 700 ms, release at p < 0.65
