# Domain checklist (accessibility communication tools)

Use this as a prompt sheet when adding or changing a feature.

- [ ] Can someone use it with **keyboard only**? With a **screen reader**? With **one hand** or **touch only**?
- [ ] Does every **live output** reach a screen reader (`aria-live`)?
- [ ] Does it work in all **12 modes**, at **200% text**, at **320 px** width?
- [ ] Does anything **move on its own**? Is it off in the calm, focus and autism modes and under reduced motion?
- [ ] Is every **ML output** shown with a confidence and a "not sure" path?
- [ ] Is it clear **where the data goes** (privacy strip)?
- [ ] Does it work **without the server**? If not, what does the user see?
- [ ] Are **sign assets** credited and licence-clean?
- [ ] Does the wording avoid claiming **translation** of sign language?
- [ ] Is the **Hindi / Indian** case handled (ISL, Bharati, hi-IN voice and recognition)?
- [ ] Does it add **weight** to the first load? (It must not.)
- [ ] Is it **free** to run?
